# Programming Basics, Groovy, and JavaScript Learning Lab

A dependency-free local app for learning programming basics first, then Groovy scripting and JavaScript side by side.

## Open the app

Open `index.html` in a browser.

## What is included

- Guided beginner lessons for programming concepts, scripts, variables, conditions, collections, and functions.
- Side-by-side Groovy and JavaScript examples.
- A JavaScript practice pad with local output.
- Explain, Debug, and Find Faults tools for beginner JavaScript practice.
- Practice prompts that show what to try after each lesson.
- Groovy samples you can copy into a `.groovy` file and run with the Groovy command-line tool.
- Quick quizzes and progress saved in browser local storage.

## Run Groovy locally

Install Groovy from the official Groovy website or through a package manager, then run:

```powershell
groovy hello.groovy
```

## Run JavaScript locally

The app can run simple JavaScript examples in the browser. If Node.js is installed, you can also save JavaScript in a `.js` file and run:

```powershell
node hello.js
```
